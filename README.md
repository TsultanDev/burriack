# Burriack — Crystal Rush

A small third-person 3D arena game for Godot 4.7. Low-poly neon visuals, no external assets: the arena, materials, HUD, and sound effects are all generated by the project.

## Run

Open the project in Godot 4.7+ and press **F5**, or run:

```sh
godot --path .
```

## Play

Collect all **12 shards** scattered around the arena while five stalkers hunt you. Shoot them, keep moving, and don't run out of integrity.

| Input | Action |
| --- | --- |
| `WASD` | Move |
| `Shift` | Sprint |
| `Space` | Jump |
| Mouse | Look |
| Left click | Fire |
| `Esc` | Release / capture cursor |
| `R` / `Enter` | Restart |

Holding the fire button keeps shooting. Stalkers respawn a few seconds after they are destroyed, so the arena never stays quiet.

## Project layout

- `scenes/main.tscn` — environment, lighting, and game root
- `scenes/player.tscn` — third-person controller with spring-arm camera
- `scenes/crystal.tscn` — collectible shard
- `scenes/enemy.tscn` — hovering stalker
- `scripts/main.gd` — procedural arena builder and game loop
- `scripts/hud.gd` — code-built HUD and end screens
- `scripts/sfx.gd` — synthesized sound bank (autoload)
- `shaders/floor_grid.gdshader` — anti-aliased neon floor grid

## Tests

A headless integration test checks spawning, movement, shooting, damage, pickups, and the win/lose flow:

```sh
godot --headless --path . --script res://tests/game_test.gd
```

`tests/screenshot.gd` renders one frame to `tests/shot_main.png` when a display is available.
